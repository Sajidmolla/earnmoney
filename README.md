# EarnTaskPro - Complete Cloud Earning Platform (No Referral)

A clean task-based earning platform without referral requirements. Direct signup using Name, Email, Phone, and Password.

## 🚀 Setup & Deployment
1. Go to https://supabase.com and create a free project.
2. Open **SQL Editor**, paste the code from `database.sql` and run it.
3. Push these files to GitHub.
4. Import to Vercel and add Environment Variables:
   - `SUPABASE_URL`
   - `SUPABASE_KEY`
5. Deploy!
